# 撰寫模組 API 文件

API 文件放在 `src/pretend2paint/<模組>/README.md`，給**其他模組的人**看：他們不讀你的程式碼，只看這份文件就要知道怎麼用。

## 原則
- 只寫**公開** API（在 `<模組>/__init__.py` 匯出的東西）。內部細節不寫。
- 文件與程式碼要一致：先確認函式簽名、型別和實際程式相同；程式還沒寫時，在標題標註「（規劃中）」。
- 跨模組用到的型別請寫 `common.types` 裡的名字。

## 格式

```markdown
# <模組> — <一句話說明>

負責人：<名字>

## 概觀
這個模組做什麼、不做什麼（2–4 行）。在分層中的位置：被誰呼叫、呼叫誰。

## 快速使用
（最短的可執行範例，從 import 開始）

## API

用途說明。

| 參數 | 型別 | 說明 |

#### `method(arg: Type) -> ReturnType`

```
