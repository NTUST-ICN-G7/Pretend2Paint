## 0. 一分鐘看懂

大家畫同一個東西，只有**間諜**不知道是什麼。間諜只拿到一句提示，外加偷看一張別人的畫，然後也要畫一張假裝自己知道。
所有畫作匿名播放、檢舉寫字的作弊畫，最後一般玩家投票找出間諜。被抓到的間諜還有一次猜答案翻盤的機會。

---

## 1. 名詞

| 名詞 | 說明 |
| :--- | :--- |
| 玩家 | 參加遊戲的真人，**4～10 人** |
| 開房者 | 建立房間的玩家。他的電腦同時執行「遊戲伺服器」，他本人也是一般參賽者，沒有額外遊戲特權 |
| 遊戲伺服器 | 開房者電腦上的自動程式，負責出題、選間諜、計時、收畫、收票、判定、計分；保管所有秘密 |
| 一般玩家 | 拿到完整答案的玩家 |
| 間諜 | 每局 1 人，只拿到提示 |
| 局（attempt） | 從發題到結算的一次遊戲。作廢局也是一局 |
| 回合（round） | **完成**的局。作廢局不算回合 |
| 畫作編號 | D1、D2…，每局重新隨機分配，審查和投票時只看得到編號，看不到作者 |
| 清白畫 | 間諜拿去參考的那張畫；它的作者一定不是間諜 |

## 2. 房間與開始　APPROVED（架構）／LEADER APPROVAL REQUIRED（人數）

- 開房者建立房間，他的電腦開始執行遊戲伺服器（ADR 0007）。
- 其他玩家在大廳看到房間、輸入**暱稱**加入；暱稱重複時自動加編號。
- 開房者可以調整設定（回合數、各階段秒數），人數 **4～10 人**時可以按開始。
- 遊戲開始後不能再加入。

## 3. 一局的流程

```text
發題 → 一般玩家畫圖 → 間諜行動 → 審查 → 投票 → （猜詞）→〔伺服器內部結算〕→ 公開畫面 → 分數畫面 → 下一局
```

伺服器在**公開之前**就完成結算（決定分數、寫入紀錄），玩家看到的畫面順序則是「公開 → 分數」。

### 3.1 發題（5 秒）　APPROVED（基本）／LEADER APPROVAL REQUIRED（加權）

- 伺服器從題庫抽一題（同一場不重複；題庫用完才重新開始，且不會連續兩局同一題）。
- 伺服器選 1 位間諜：**加權隨機**，當過越多次間諜越不容易再被選到（權重 1/(1+s)²，s＝已完成回合中當過間諜的次數），但仍可能連續當。
- **一般玩家**私下收到答案（例：「西瓜」）；**間諜**私下收到提示（例：「兩個字的水果」）。每個人只看得到自己的。

### 3.2 一般玩家畫圖（30 秒）　LEADER APPROVAL REQUIRED（交圖細節）

- 一般玩家同時在各自的空白畫布上畫（不是接龍），看不到別人的畫。
- 可以按「交出」，**可以重複交**，以最後一次為準。
- 倒數到 0，畫布鎖住並自動交出；沒畫也算交白紙。
- 間諜這段時間看到等待畫面。

### 3.3 間諜行動（30 秒）　LEADER APPROVAL REQUIRED（改為自動抽圖）

- 伺服器**自動**從一般玩家的畫裡隨機抽 1 張，私下給間諜看（不告訴他是誰畫的）。
- 間諜參考這張圖畫自己的畫，交圖方式同上。
- 一般玩家這段時間看到等待畫面。

### 3.4 審查（每張 5 秒）　LEADER APPROVAL REQUIRED

- 所有畫（含間諜的）以**隨機順序、一次一張**播放給**一般玩家**看，每張 5 秒，只顯示畫作編號。
- 看到畫裡有**可辨認的文字**（不論是不是答案），可以按「檢舉」；預設不檢舉。
- 每人每局可檢舉的張數有上限：

  | 人數 | 4～5 | 6～7 | 8～9 | 10 |
  | :--- | :---: | :---: | :---: | :---: |
  | 每人可檢舉張數 | 1 | 2 | 3 | 4 |

- 同一張畫得到 **⌈2(N−1)/3⌉** 張檢舉票（N＝本局人數）就判定**違規**。例：5 人局要 3 票。
- 自己的畫也可以檢舉。**間諜看不到審查畫面、不能檢舉。**
- 被暫停審查權的人（見 4.2）看得到畫，但檢舉鍵不能按。
- 違規的畫**仍然可以被投票**，但之後間諜猜詞時看不到它。

### 3.5 參考圖違規 → 本局作廢　LEADER APPROVAL REQUIRED

- 如果**間諜拿到的那張參考圖**被判違規，本局立刻作廢：跳過投票和猜詞，所有人本局的勝負分為 0，但違規處罰照算（見 4.2）。
- 作廢局不算回合，伺服器會重新開一局（新題目、新間諜、新編號）。
- 間諜自己的畫或其他沒被參考的畫違規，**不會**作廢。

### 3.6 投票（30 秒）　LEADER APPROVAL REQUIRED

- **只有一般玩家能投票**，間諜看到等待畫面。
- 一般玩家看到所有畫（只有編號），其中清白畫會被標記出來。
- 每人投 1 票給某個畫作編號，**不能投自己的畫、不能投清白畫**。
- 可以按「棄票」（之後不能再投）；時間到沒投也算棄票。
- 投票期間**看不到任何人的票數**。每人只算第一張有效票。

### 3.7 投票結果　LEADER APPROVAL REQUIRED

| 投票結果 | 接下來 |
| :--- | :--- |
| 間諜的畫拿到**唯一**最高票 | 間諜被抓，進入猜詞 |
| 某位一般玩家的畫拿到**唯一**最高票 | 間諜**逃脫**，不用猜 |
| **所有一般玩家都棄票** | 間諜**逃脫**，不用猜 |
| 有人投票但最高票**平手** | 進入猜詞 |

### 3.8 間諜猜詞（30 秒）　APPROVED（被抓要猜）／LEADER APPROVAL REQUIRED（平票也猜、可見範圍）

- 間諜看得到**沒被判違規**的畫，輸入一次答案。
- 比對時忽略全形半形、空白、大小寫；題目設定的別名也算對（例：「watermelon」）。
- 時間到沒猜＝猜錯。

### 3.9 結算、公開（10 秒）與分數畫面（10 秒）　LEADER APPROVAL REQUIRED

1. **結算（伺服器內部，玩家看不到）**：投票或猜詞結束時，伺服器一次算好本局分數、處罰與紀錄。每局只結算一次，之後不再改變。
2. **公開畫面**：答案、提示、誰是間諜、每張畫的作者、哪些違規、每張畫的得票數。
3. **分數畫面**：本局每人加減分與累計分數。
4. 完成 **5 回合**（作廢局不算）後遊戲結束；否則開始下一局。

## 4. 計分

### 4.1 勝負分　LEADER APPROVAL REQUIRED（數值為暫定，試玩後調整）

N＝本局人數，**base＝5＋3×(N−4)**（4 人＝5、5 人＝8、7 人＝14、10 人＝23）。

| 結果 | 間諜 | 投中間諜的一般玩家 | 其他一般玩家 |
| :--- | :---: | :---: | :---: |
| 一般玩家唯一最高票（逃脫） | +3 | base | 0 |
| 所有一般玩家棄票（逃脫） | +3 | — | 0 |
| 間諜被抓，猜對 | +1 | base | 0 |
| 間諜被抓，猜錯或逾時 | −3 | base＋3 | 0 |
| 平票，猜對 | +1 | base | 0 |
| 平票，猜錯或逾時 | 0 | base | 0 |
| 參考圖違規作廢 | 0 | 0 | 0（處罰照算） |
| 斷線作廢 | 0 | 0 | 0（處罰也不算） |

### 4.2 處罰　LEADER APPROVAL REQUIRED

| 對象 | 情況 | 處罰 |
| :--- | :--- | :--- |
| 畫作者 | 第 1 次被判違規 | −15 分 |
| 畫作者 | 第 2 次被判違規 | 該局結算後**移出本場遊戲** |
| 檢舉者 | 連續第 3 次檢舉失敗（那張沒被判違規） | −3 分 |
| 檢舉者 | 連續第 4 次檢舉失敗 | 再 −6 分，並暫停下一次審查權，連續次數歸零 |

- 檢舉成功一次，連續失敗次數歸零；沒按檢舉不算失敗。
- 如果暫停會讓違規門檻不可能達成，暫停會延後執行。
- 處罰加在勝負分之後。

### 4.3 排名　LEADER APPROVAL REQUIRED

- 同分同名次。
- 被移出或中途離開的人列在「已離開」清單，保留分數，但**不參加排名和冠軍**。

## 5. 斷線　LEADER APPROVAL REQUIRED（討論：Issue #8）

以「**結算確定**」為分界點（投票或猜詞結束、伺服器算完分數的那一刻）。

| 誰、什麼時候斷線 | 處理 |
| :--- | :--- |
| 開房者（伺服器）任何時候 | 遊戲結束。每位玩家顯示**最後一次收到的分數**，並標示「截至第 N 回合」；如果一次分數都還沒收到，顯示「遊戲中斷，尚無分數」 |
| 玩家，在大廳 | 從名單移除 |
| 玩家，結算確定**之前** | 本局**作廢**：公布本局答案、間諜和畫作，**完全不計分**（含本局處罰），不算回合，把他移出後重開一局 |
| 玩家，結算確定**之後**（公開、結算畫面） | 本局結果照算，下一局開始前移出 |
| 任何時候移出後剩不到 4 人 | 遊戲結束 |

第一版不支援斷線重連。

### 斷線的偵測與先後順序

- 斷線由心跳逾時判定，會有幾秒延遲。
- 伺服器依事件抵達的先後一件一件處理：例如「參考圖違規」和「有人斷線」幾乎同時發生，**先被處理的那件決定本局結果**，後到的不再改變。

## 6. 誰看得到什麼（機密規則）　LEADER APPROVAL REQUIRED（ADR 0008，部分取代 ADR 0005）

| 階段 | 一般玩家 | 間諜 |
| :--- | :--- | :--- |
| 發題 | 答案 | 提示 |
| 一般玩家畫圖 | 只有自己的畫 | 等待 |
| 間諜行動 | 等待 | 1 張參考圖（不知道作者） |
| 審查 | 逐張看所有畫（只有編號） | 等待 |
| 投票 | 所有畫（只有編號）＋清白標記，看不到票數 | 等待 |
| 猜詞 | 等待 | 沒違規的畫 |
| 公開 | 全部 | 全部 |

- **結果確定前**：答案、提示、角色只**單播**給本人；作者對應、別人的角色、別人的票和檢舉只有伺服器知道。
- **結果確定前的畫作例外**：參考圖只給間諜；審查與投票時，畫作以匿名編號逐一單播給一般玩家；猜詞時未違規的畫只給間諜。都不附作者、都不廣播。
- **結果確定後**：伺服器才廣播公開答案、提示、間諜、作者、違規與得票數。
- 詳細條文見 ADR 0008（部分取代 ADR 0005）。
