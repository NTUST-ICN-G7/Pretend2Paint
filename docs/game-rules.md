# 遊戲規則：P2P 誰是臥底・畫圖版

> 來源：ICN Group Meet 0。規則有變動時請更新這份文件，並同步調整 `common/types.py` 的 `Phase`。

## 名詞

| 名詞 | 說明 |
| :--- | :--- |
| 一般玩家（Civilian） | 拿到完整答案的玩家 |
| 間諜（Spy） | 每回合一名，只拿到答案的提示 |
| 房主（Host） | 建立房間、**同時參與遊戲**的玩家，另有大廳管理權限。權威裁判邏輯在該玩家的遊戲程式內自動執行；不另設真人或獨立程序（見 [ADR 0007](decisions/0007-in-process-referee.md)）。 |

## 流程

### 0. 局外 Landing space（`Phase.LOBBY`）
玩家透過 UDP broadcast 發現彼此、加入房間。

### 1. 發題（`Phase.DEAL`）
- 選詞或隨機生題。
- 一般玩家拿到**完整答案**；間諜只拿到**提示**。
  - 例：答案「西瓜」→ 提示「兩個字的水果」。

### 2. 畫圖階段（`Phase.DRAWING`）
- 所有一般玩家**各自從白板開始畫**（不是接龍）。
- 此階段畫好的圖**不公開**。

### 3. 間諜行動階段（`Phase.SPY_ACTION`）
- 間諜從已完成的畫作中**盲選 1 張**作為參考。
- 間諜看著參考圖開始畫圖。

### 4. 公開階段（`Phase.REVEAL`）
- 所有人的畫作公開。
- 被間諜選中參考的畫作會被**標記**（代表該作者一定不是間諜）。

### 5. 投票（`Phase.VOTING`）
所有人投票選出自己認為的間諜。

### 6. 間諜猜答案（`Phase.SPY_GUESS`，僅在間諜被票出時）
間諜有一次機會猜正確答案。

### 7. 結算（`Phase.ROUND_END`）

| 情況 | 結果 |
| :--- | :--- |
| 間諜**沒有**獲得最高票 | 間諜得分 |
| 間諜被票出，且猜對答案 | 間諜得分 |
| 間諜被票出，且猜錯答案 | 間諜扣分 |

> 待定：一般玩家的計分方式、平票處理、遊戲共幾回合。由 Core 提案後更新此文件。
