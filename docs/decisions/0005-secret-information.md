# 0005. 機密資訊只能單播

- 狀態：通過
- 日期：2026-11-20
- 決策者：banahaker（team leader）

## 背景
所有節點都能收到廣播封包。如果答案被廣播，間諜只要看封包內容（或修改程式）就能知道答案，遊戲就不成立。

## 決定
- **答案、提示、間諜身分**：只能由房主單播給對應的玩家，任何時候都不能廣播。
- **畫作**：`Phase.REVEAL` 之前只能送給房主；間諜只會收到房主轉送的那一張參考圖。
- 答案只在回合結算（`ROUND_RESULT`）才公開。

## 影響
- p2p 必須提供「送給指定 peer」的 API，不能只有廣播。
- 詳細封包列表見 [protocol.md](../protocol.md)。
