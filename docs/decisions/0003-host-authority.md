# 0003. 由房主作為權威節點

- 狀態：通過
- 日期：2026-11-20
- 決策者：banahaker（team leader）

## 背景
遊戲需要有人出題、指定間諜、收票與計分。完全去中心化（所有節點共識）的做法對期末專案來說過於複雜，且容易出現各節點狀態不一致。

## 決定
- 建立房間的玩家是**房主（host）**，負責：出題、指定間諜、推進階段、收集畫作與投票、計分、廣播結果。
- 其他玩家只送出自己的動作（畫作、選參考圖、投票、猜答案）給房主。
- 網路拓樸仍是 TCP full-mesh（由 p2p 維護），但遊戲狀態以房主為準。

## 影響
- 房主知道答案與間諜身分，因此**房主本身不能當間諜**，或接受房主可以作弊（課堂專案可接受）。由 Core 決定並記錄。
- 房主斷線的處理（換房主或結束遊戲）由 Core 與 P2P 提案。
